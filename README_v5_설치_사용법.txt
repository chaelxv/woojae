양우재와 둥의 소소한 하루 — v5.1 웹게임 전체 소스
=================================================

[실행]
- 압축을 풀고 index.html을 브라우저로 여시면 기본적으로 플레이할 수 있습니다.
- PC/모바일 웹 배포는 GitHub Pages를 권장하며, index.html, game.js, styles.css, sw.js, manifest.webmanifest, icon PNG 및 assets 폴더를 모두 같은 경로에 업로드해 주세요.
- 반드시 ZIP을 해제하여 파일을 올려야 하며, ZIP만 GitHub에 업로드하면 실행되지 않습니다.

[중요: 기존 데이터 안전]
- 업그레이드 전 웹사이트 내에서 설정 > 백업 내보내기로 JSON 파일을 보관해 주세요.
- 기존 save key (yang-woojae-doong-save-v2)를 그대로 사용하며 기존 버전의 유효한 기록을 이어서 읽습니다.
- 브라우저별·기기별로 저장 데이터가 별도이며 자동 클라우드 동기화는 없습니다.
- iPhone Safari의 홈 화면 앱은 Safari 탭과 저장 공간이 다를 수 있으므로, 이동 전에 JSON 백업이 필요합니다.
- 사이트 데이터 삭제 시 저장된 게임 데이터가 삭제될 수 있습니다.

[v5.1 기능]
1. 홈: 실제로 이동하는 양우재 스프라이트, 둥, 대파 인형, 가구 이동, 표정 변화 및 하트 파티클
2. 옷장: 10종 고화질 개별 투명 PNG, 카드 클릭·필터·즐겨찾기·표정 6종 선택
3. 목욕: 샴푸 → 헹구기 → 수건으로 닦기, 포인터·터치 드래그 + 접근성 버튼
4. 수면: 이불 위로 드래그, 전등 끄기, 밤 화면과 체력 회복
5. 요리: 6가지 요리, 재료 드래그 → 칼질 → 섞기 → 불/조립/양념을 레시피에 맞춰 처리
6. 식탁: 실제 보유 중인 음식 중 선택, 음식별 다른 일러스트, 3회 먹이기 후 정확한 요리 재고 감소
7. 상점: 코인으로 소품 구매, 간식·둥의 장난감 등 추가 상호작용
8. 일기장: 이벤트 기록과 업적 6종
9. 저장: LocalStorage + IndexedDB 보조저장 + 수동 JSON 백업·복원
10. 배경음악과 음원 없음

[이미지 정리]
- assets/characters/expressions/*.png: 양우재 표정·동작 12종, 동일 크기 투명 PNG
- assets/characters/outfits/*.png: 의상 10종, 동일 크기 투명 PNG
- assets/food/*.png: 서로 다른 음식 그림
- assets/scenes/*.webp: 집, 목욕, 수면, 식사 등 배경
- assets/props/*.png: 둥/대파 인형

[제약/테스트]
- 이번 작업에서 JavaScript 구문, 이미지 파일 완전성, 주요 레시피 데이터 경로 및 저장형식 단위 테스트를 통과했습니다.
- 현재 실행 환경에서 Chromium은 URLBlocklist 정책으로 페이지 탐색이 막혀 실제 브라우저 클릭 시나리오의 자동 테스트를 끝까지 수행할 수 없었습니다.
- 배포 후 iOS/PC 환경의 실제 터치와 반응성은 추가 확인이 필요합니다.
