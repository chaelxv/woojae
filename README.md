# 우재와 예린이 — 식사 화면 수정 v5.5

GitHub Pages 루트 업로드용 전체 게임 폴더입니다. 이 폴더 **안에 있는 항목들**을 GitHub 저장소의 최상위에 올려주세요. ZIP 자체나 바깥 폴더를 올리면 안 됩니다.

- 식사 화면: 기존 배경의 중복 캐릭터·음식·문구 제거, 신규 식탁 그림 (`assets/scenes/feed_clean.webp`) 사용
- 우재 캐릭터 앞 중앙에 선택한 음식이 표시됩니다.
- 식사 보관함에서 음식을 바꾸면 접시에 올려진 음식도 함께 변경됩니다.
- 모바일에서는 식사 화면 비율과 캐릭터·음식 위치를 별도로 조정합니다.
- 기존 저장 키/저장 데이터 구조는 그대로 유지합니다.
- JavaScript 문법과 경로 점검 및 자동 브라우저 테스트 결과는 별도 안내를 참고해 주세요.
- 오디오/배경음악을 포함하지 않습니다.

업로드 후 최신 화면이 나타나지 않으면 GitHub Pages 배포 완료를 확인하고 브라우저 새로고침을 해주세요. `sw.js`의 캐시 이름을 업데이트했습니다.
