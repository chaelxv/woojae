# 우재 게임 v5.4 — GitHub Pages 업로드용

이 폴더의 **내용물**을 GitHub 저장소 `chaelxv/woojae`의 최상위(`main` 브랜치)에 업로드하세요.

## 업로드 순서
1. GitHub 저장소의 **Code → Add file → Upload files**로 이동합니다.
2. 이 폴더 안의 `index.html`, `game.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `assets` 폴더 등 **모든 내용물**을 선택해 업로드합니다.
3. 동일한 이름의 기존 파일은 변경 내용으로 대체하고, 화면 아래의 **Commit changes**를 누릅니다.
4. **Settings → Pages**에서 `Deploy from a branch / main / (root)` 설정을 확인합니다.
5. 배포가 완료되면 https://chaelxv.github.io/woojae/ 에 접속합니다.

**주의:** ZIP 파일 자체를 업로드하지 마세요. ZIP을 압축 해제하고, 그 안에 있는 파일과 폴더를 업로드해야 합니다. GitHub 최상위에 `index.html`이 있어야 합니다.

이 파일 묶음은 v5.4를 **업로드하기 편하도록 정리한 것**이며, 게임 기능 변경은 포함하지 않습니다.
