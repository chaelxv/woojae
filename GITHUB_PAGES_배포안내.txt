양우재와 둥의 소소한 하루 — GitHub Pages 배포 안내

이 ZIP에 포함된 index.html, styles.css, game.js, assets/ 등의 파일은 GitHub Pages에서 정적 웹사이트로 실행할 수 있습니다.

1. GitHub에서 새 public 저장소를 생성합니다. 예시 저장소 이름: woojae-doong-day
2. ZIP 압축을 풀고, 폴더 안의 *내용물* 전체를 저장소의 기본 브랜치(main) 루트에 업로드합니다.
   (ZIP 파일 하나만 업로드하면 안 됩니다. index.html 파일이 루트에 있어야 합니다.)
3. GitHub 저장소 Settings > Pages > Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch: main, Folder: /(root)로 설정한 후 Save합니다.
5. Pages 화면에 표시되는 실제 사이트 URL을 방문합니다. 보통 https://<github-username>.github.io/<repository>/ 형태입니다.

[모바일 및 저장]
- HTTPS 사이트에서 홈 화면에 추가하면 설치형 웹앱(PWA)처럼 실행할 수 있습니다.
- 자동 저장은 현재 사용하는 브라우저/앱의 로컬 저장소에 기록됩니다.
- 다른 도메인으로 옮기거나 브라우저 기록을 삭제하면 저장 데이터가 이전되지 않을 수 있습니다.
- 게임 설정 > 백업 파일 내려받기를 눌러 저장 데이터를 보관하고, 새 사이트에서 불러오기로 복원하세요.
- macOS 앱과 웹사이트의 저장 데이터는 자동으로 서로 동기화되지 않습니다.

[포함 사항]
- 캐릭터: 양우재, 둥(하얀 포메라니안), 얼굴 달린 대파 인형
- 연한 오렌지/크림 배경, 방 이동, 요리 미니게임, 음식 먹이기, 옷장, 다이어리, 백업
- 음악/음원 포함하지 않음
