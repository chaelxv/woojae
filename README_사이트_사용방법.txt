양우재와 둥의 소소한 하루 — 직접 돌보기 확장판 v3.0
==================================================

[변경 사항]
1. 가구 사용: 방 안 침대, 소파, 식탁, 주방, 냉장고, 옷장, 책장, 욕실 버튼을 직접 눌러 사용합니다.
2. 쓰다듬기: 소파/둥/놀아주기를 누른 뒤 화면을 손가락 또는 마우스로 문질러 친밀도를 올립니다.
3. 목욕: 욕실/씻기기를 누른 뒤 샴푸 → 헹굼 → 수건 닦기 3단계 손동작을 완료합니다.
4. 수면: 침대/재우기를 누른 뒤 이불을 위쪽으로 끌어올리고 전등을 눌러 재웁니다.
5. 요리: 재료 드래그 → 칼질 스와이프 6회 → 원형으로 섞기 → 불 조절 및 타이밍 맞춰 뒤집기까지 4단계입니다.
6. 식사: 직접 만든 요리를 식탁에서 선택하면 우재가 걸어가서 식탁에서 먹는 애니메이션이 나옵니다.
7. 옷장: 분리 과정에서 잘렸던 머리카락/귀를 보완하기 위해 원본 머리 표현을 기준으로 의상 컷을 재조합하고, 투명 PNG와 전신 여백을 교정했습니다.
8. 저장: 기존 v2 저장 데이터를 그대로 불러옵니다. 브라우저 자동 저장, IndexedDB 이중 저장, JSON 백업/복원이 유지됩니다.
9. 음악 및 음원 없음.

[GitHub Pages에서 기존 사이트 교체]
1. 현재 웹사이트의 게임 데이터가 소중하다면 설정 > 백업 파일 내려받기를 먼저 실행하세요.
2. 이 ZIP을 압축 해제합니다.
3. GitHub 저장소 chaelxv/woojae 에서 'Add file > Upload files'를 열고, 루트 폴더의 파일과 assets 폴더 내부의 이미지를 같은 경로/파일명으로 올려 기존 파일을 교체합니다.
   특히 index.html, styles.css, game.js, sw.js, assets 폴더를 반드시 함께 교체해야 합니다.
   ZIP 파일 하나만 업로드하면 GitHub Pages에서 게임이 갱신되지 않습니다.
4. Commit changes 저장. GitHub Actions의 pages build and deployment가 녹색으로 바뀌면 사이트를 새로고침합니다.
5. 예전 화면이 남아 있으면 사파리/크롬에서 사이트를 새 탭으로 열거나 사이트 데이터의 캐시를 지운 뒤 다시 접속합니다. 캐시/사이트 데이터 삭제 시 저장이 지워질 수 있으므로 반드시 JSON 백업 후 진행하세요.

[자동 저장]
- 기존 저장 키는 yang-woojae-doong-save-v2이며 저장 파일 포맷도 v2로 유지되어 기존 진행 상황과 호환됩니다.
- 같은 브라우저, 같은 사이트 주소에서 게임 진행 상황이 이어집니다.
- 브라우저 삭제/시크릿 모드/다른 기기에서는 저장이 보장되지 않습니다. 동기화 기능은 아직 없습니다.
- JSON 백업을 주기적으로 파일 앱/드라이브에 보관하고 필요시 불러오세요.

[macOS]
- macOS 빌드키트 ZIP의 Web 폴더에도 같은 v3 게임 파일이 포함됩니다.
- 실제 .app 컴파일은 macOS와 Xcode Command Line Tools 설치가 필요합니다.

[권장 환경]
- 데스크톱: Safari/Chrome 최신 버전, 마우스 또는 트랙패드
- 모바일: Safari/Chrome 최신 버전, 손가락으로 드래그 / 스와이프
- 온라인 배포: GitHub Pages의 HTTPS 주소

[참고]
게임은 독립 웹 프런트엔드 과제용 프로토타입입니다. 2D 절차 애니메이션과 터치 조작이 구현되어 있으며 별도 사운드는 포함하지 않습니다.
