양우재와 둥의 소소한 하루 · 개인 과제용 웹 게임 v2.0

[이름 및 그래픽]
주인공: 양우재 / 하얀 포메라니안: 둥 / 소품: 눈·코·입이 그려진 대파 인형 1개
연한 오렌지·크림·우드 톤의 별도 제작 방 이미지와 소품을 사용합니다.
음원, 배경음악, 오디오 파일은 하나도 들어있지 않습니다.

[실행]
압축 해제 후 index.html을 클릭하면 브라우저에서 플레이할 수 있습니다.
모바일까지 제대로 사용하거나 홈 화면에 게임을 설치하려면 전체 사이트 폴더를 HTTPS 서버에 배포하세요.
웹사이트 배포용 파일: index.html / game.js / styles.css / assets/ / sw.js / manifest.webmanifest / icon-192.png / icon-512.png.

[사이트 게시 예시]
GitHub Pages, Netlify, Cloudflare Pages 등 정적 사이트 호스팅에 폴더를 통째로 올리면 됩니다.
(호스팅 완료 전에는 누구나 열 수 있는 실제 공개 URL이 생성되지 않습니다.)
HTTPS 접속에서 오프라인 웹앱(PWA) 저장을 지원합니다.

[기능]
• 방 빈 바닥 클릭/터치 → 우재가 걸어다니기(이동 애니메이션)
• 둥 클릭 → 둥 쓰다듬기/반응/친밀도
• 눈·코·입 대파 인형 클릭 → 놀이/반응
• 식사, 놀아주기, 씻기기, 잠, 대화 및 시간/상태 관리
• 레시피 4종, 3단계 요리 미니게임, 음식 획득 및 식탁 먹기 애니메이션
• 의상 9종 및 다이어리, 코인
• 자동 저장 + 파일 백업 다운로드/복원

[저장 유의사항]
웹에서 localStorage와 IndexedDB를 모두 사용하고 저장하기 위해 시도하지만,
시크릿 모드, 브라우저 데이터 삭제, 저장소 부족 또는 OS 정리로 데이터가 사라질 수 있습니다.
'설정·저장 > 백업 파일 내려받기'로 정기적으로 별도 JSON 파일을 보관하고,
기기 변경 시 '백업 파일 불러오기'로 복원하세요.
웹 버전과 macOS 앱 간 저장 상태는 직접 공유되지 않으며 백업 파일로 옮길 수 있습니다.

[macOS 앱]
별도로 제공하는 macOS 빌드키트는 Swift/WebKit 앱 소스와 원본 웹 자산을 포함합니다.
Mac에서 빌드 스크립트를 실행하면 .app이 생성되고, 맥 앱은
~/Library/Application Support/WoojaeDoong/save-v2.json 에 별도 자동 저장합니다.

[배포 상태]
개인용 개발 프로토타입. 호스팅/앱 개발자 서명/공증/스토어 출시는 수행하지 않았습니다.
